# prototype2 검토 안내

**보는 곳:** https://hyfin.duckdns.org/hyrealty-p2/ (운영판 `/hyrealty/` 는 그대로)
**브랜치:** `prototype2` — master 에 머지하지 않았습니다. 검토 뒤 반영 여부를 정합니다.
설계서: `docs/prototype2/DESIGN.md`

## 바뀐 것 (참고 사이트 → 우리 자료로)

| 기능 | 참고 | 어디서 보나 | 무엇을 보여 주나 |
|---|---|---|---|
| 오늘 볼 것 | 플래닛·R114 첫 화면 | 모든 탭 맨 위 카드 · 머리줄 "오늘 볼 것" | 전세 신호 요약 · 남은 후보 상위 · 청약 새 공고 · 시장 온도 한 줄 — 누르면 해당 화면 |
| 단지 상세 | 호갱노노 | 후보판 단지 이름 옆 **상세** · 전월세 찾기 ③ 단지 이름 | 같은 단지·평형 매매·전세 분기 추이 차트, 전세가율 추이, 평형별 표, 최근 분기 거래, 전세 만기 일정 |
| 동네 시세판 | R114·플래닛 | ＋ 청약·전월세 → 동네 시세판 | 동별 전세·매매 중위(㎡당), 전세가율, 거래량 1년 변화, 신축 비중 — 정렬·색 칸, "이 구에서 발굴하기" |
| 시장 온도 | 한국부동산원 판단지표 | 4 실거래 수익률 탭 맨 위 | 구별 거래량 추세 · 전세가율 추세 · 매매/전세 1년 변화를 **나란히** (합산 점수 없음) |
| 배너 | — | 머리줄 맨 위 (`VITE_PROTOTYPE=2` 빌드에서만) | 바뀐 것 요약 |

공식 API 가 없는 곳(호갱노노·플래닛·R114·KB)은 크롤링하지 않았고, 기능만 국토부 실거래·청약홈·전세 신호 자료로 만들었습니다.

## 검토 순서 (5분)
1. 첫 화면 "오늘 볼 것" 카드 → 항목 하나씩 눌러 이동이 맞는지
2. ＋ 청약·전월세 → 전·월세 후보판 → 단지 이름 옆 **상세** → 차트·만기 일정
3. ＋ 청약·전월세 → 동네 시세판 → 정렬·색 칸 · "이 구에서 발굴하기"
4. 4 실거래 수익률 → 맨 위 시장 온도

## 확인한 것
- 타입체크 · 단위 테스트 569건 통과 · 채점표 100/100 (상시 탭 6개 유지, 외부 요청 0건)
- headless 크롬으로 빌드 문서를 열어 `#root` 가 그려지고 배너·"오늘 볼 것" 이 나오는 것
- 서버 `/hyrealty-p2/index.html` 이 빌드와 바이트 단위로 같음, `signals.json` 은 운영판 파일로 심볼릭 링크(같은 신호를 봄)

## 확인 생략 (지시대로)
- 브라우저 스크린샷·클릭으로 하는 화면 점검 — 배치·겹침·문구는 직접 봐 주세요
- 설계·구현을 Opus 높음 이상으로 해서 별도 검토 에이전트는 두지 않았습니다

## 남은 것 · 알아 둘 것
- 스냅샷이 분기 중위라 "최근 거래" 는 개별 거래가 아니라 **최근 분기** 단위입니다.
- 매매 스냅샷(2026Q2까지)과 전세 스냅샷(2026Q3까지)의 마지막 분기가 달라, 1년 변화 창을 각각 잡고 라벨에 적었습니다.
- 동네 시세판·시장 온도의 얇은 표본(거래 몇 건)은 흐리게 표시하거나 빼는 기준이 설계서에 있습니다.
- `deploy:realty-p2` 는 `realty/index.html` 을 덮어씁니다 — p2 빌드를 master 에 커밋하면 GitHub Pages 에 p2 가 올라가니 주의(이번엔 되돌려 두었습니다).
- 운영 반영: 검토 후 말씀하시면 `prototype2` → master 머지, 배너 없이 운영 빌드로 배포합니다.
