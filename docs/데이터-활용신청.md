# 희용님이 하셔야 할 것 — 데이터 활용신청

이 저장소의 실측 데이터는 전부 **빌드 타임에 받아 JSON으로 굽습니다.**
정적 단일 HTML이라 런타임에 키를 둘 수 없기 때문입니다.

키는 `.env.local` (gitignore)에 있고 지금 4종이 등록돼 있습니다.
아래 둘은 **API별 활용신청이 따로 필요**하고, 그건 희용님 계정에서만 됩니다.

---

## 1. 행안부 주민등록 인구통계 → `populationTrend` 실측

**막힌 지점.** 지금 `MOLIT_API_KEY`(data.go.kr 일반 인증키)로 호출하면 이렇게 돌아옵니다.

```
{"errMsg":"SERVICE_KEY_IS_NOT_REGISTERED_ERROR","returnReasonCode":"30"}
```

data.go.kr 인증키는 계정 단위지만 **활용신청은 API 단위**입니다. 신청이 안 된
API는 같은 키로도 안 열립니다.

**하실 일**

1. <https://www.data.go.kr> 로그인
2. "주민등록 인구통계" 검색 → 행정안전부 제공 오픈API
3. `활용신청` → 활용목적에 "개인 주택 매수 의사결정 도구 (비영리)" 정도로 기재
4. 승인은 보통 즉시~1영업일. 마이페이지 > 오픈API > 개발계정에서 상태 확인

**승인 뒤**

`.env.local` 의 `MOLIT_API_KEY` 를 그대로 씁니다 (같은 계정 = 같은 키).
알려 주시면 수집 스크립트를 붙이겠습니다 — 시군구별 인구 추세를 내서
`populationTrend` 주관 입력 옆에 실측 신호로 놓습니다. UI 자리는 이미 있습니다
(`＋ 물건 · 입지` 탭 > 인구·일자리 추이 > "실측 대기").

**왜 값어치가 있나.** `populationTrend` 는 창원 가중치가 **10** 으로 전체 지표 중
가장 높습니다. 지금 이 축이 순수 주관인데, 창원은 인구 유출이 실제 쟁점입니다.

## 2. 공동주택관리정보시스템(K-apt) → 수선유지비 0.5% 실측

**막힌 지점.** 룰셋의 `maintenanceRate: 0.005` 는 근거가 통상값뿐입니다.
매수·청약 갈래만 부담하는 값이라, 0.5%p만 움직여도 10년 보유 기준으로
주택가격의 5%가 오갑니다.

**하실 일**

1. <https://www.data.go.kr> 에서 "공동주택 관리비" 또는 "K-apt" 검색
2. 국토교통부/한국부동산원 제공 관리비 상세 API 활용신청
3. 특히 **장기수선충당금** 항목이 있는 API를 고르세요 — 일반 관리비(청소·경비)는
   임차인도 내므로 소유자 부담인 수선유지비와 다릅니다

**승인 뒤**

단지별 장기수선충당금(원/㎡)을 받아 주택가격 대비 비율로 환산하고,
지역별 중위값을 룰셋에 굽습니다. 지금 `tenure.assumptionDefaults.basis.maintenanceRate`
에 적어 둔 `wouldSettle` 이 바로 이것입니다.

## 실측이 불가능하다고 확인된 것

키를 더 받아도 안 되는 것들입니다. 추측이 아니라 **API를 직접 두드려 확인**했습니다.

| 값 | 확인 결과 |
|---|---|
| 코스피 총수익지수(TR) | KRX 지수 API 가 주는 코스피 계열 51개가 전부 가격지수 |
| S&P500 배당수익률 | FRED 검색 결과 1969년에 끝난 NYSE 계열뿐 |
| S&P500·나스닥100 총수익지수 | FRED 에 `SP500TR`·`WILL5000IND` 등 없음 (직접 조회 실패 확인) |

그래서 가격지수 CAGR 에 배당을 더한 근사를 쓰고 화면에 그렇게 적습니다.
**코스피 배당은 ECOS 에 있어서 실측으로 바꿨습니다** (20년 평균 1.60%).
미국 지수 배당만 가정으로 남습니다 — 같은 "실측+가정" 이라도 근거 수준이
다르다는 것을 화면 문구로 갈라 뒀습니다.
