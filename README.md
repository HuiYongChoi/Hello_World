# Hello-u: 현대적 텍스트 파티클 대시보드

미래지향적 스타일의 HUD(Head-Up Display)와 상호작용하는 텍스트 파티클 시스템이 결합된 웹 페이지입니다.

## ✨ 주요 기능

- **인터랙티브 파티클 시스템**: "HELLO WORLD" 텍스트가 수천 개의 동적 파티클로 구성되어 있으며, 마우스 움직임과 클릭에 따라 실시간으로 반응합니다.
- **HUD 스타일 레이아웃**: 날짜, 위치, 실시간 시계 정보를 현대적인 인터페이스로 제공합니다.
- **실시간 위치 탐지**: 사용자의 IP 주소를 기반으로 현재 거주 도시와 국가를 자동으로 분석하여 표시합니다.
- **반응형 디자인**: 다양한 화면 크기에 맞춰 최적화된 레이아웃을 제공합니다.

## 🛠 사용 기술

- **Core**: HTML5, CSS3, Vanilla JavaScript
- **Graphics**: Canvas API (고성능 파티클 렌더링)
- **Fonts**: Google Fonts (Outfit)
- **API**: [ipapi.co](https://ipapi.co/) (IP 기반 지오로케이션)

## 🚀 시작하기

1. 이 저장소를 클론합니다:
   ```bash
   git clone https://github.com/HuiYongChoi/Hello-u.git
   ```
2. `index.html` 파일을 브라우저에서 실행합니다.

## 📸 미리보기 및 상호작용
- **마우스 호버**: 마우스 커서를 글자 위로 가져가면 파티클들이 커서로부터 멀어집니다.
- **마우스 클릭**: 클릭 중일 때는 반응 반경이 넓어져 파티클들이 더 크게 흩어집니다.
